# 第五人格 Mac 当前路线

这是一个面向 Apple Silicon Mac、首版目标 macOS 15 的非官方发布候选。当前本机安装态已用 Developer ID 签名、公证并完成麦克风实测；仓库里的源码构建与旧 DMG 仍须分别核对身份、公证、哈希和安装体验，不能因安装态通过就宣称已公开发布或所有设备可用。下载页应同时给出发行物校验值与首次授权说明。

- 国服与国际服按两个独立客户端管理；游戏文件、prefix、更新状态和日志不互相覆盖，共享一份只读 Wine/DXMT runtime。顶部服务器选择只切换当前面板，不会结束或阻止另一服运行、下载。
- 游戏文件只从网易官方动态下载入口取得，启动器不提供网络加速，也不保存游戏账号、密码或扫码会话。
- 国服已在当前候选兼容环境中通过启动、输入、声音输出和快速重启验证。
- 国际服与国服都从各自官方动态 manifest 直接下载游戏本体，不经过网易启动器界面。两服均有目录选择、空间检查、进度、暂停/继续/取消、独立 prefix、启动/结束/重启、扫描修复和“清除本服游戏”；本体写入并校验后即显示已安装，首次启动后的游戏内更新由官方客户端自己处理。
- idv-login 是两服共享的可选代理与账号后台，当前固定为 6.3.0。它不随启动器包重分发；用户同意安装时，启动器从固定上游 Release 下载，限制重定向主机，并校验大小、SHA-256 与 arm64 Mach-O。跨版本安装隔离旧热修复并保留账号、证书。启用后，启动/重启按钮先等待本地代理就绪，再由启动器精确拉起当前服务器。两服都可不用它而走官方登录。国际服扫码后持久化由首位实际国际服用户验收，不作为 RC1 封包前的本机硬门。
- 单一 `第五人格启动器.app` 内含原生下载/诊断/卸载工具和游戏 runner；不内含游戏本体、网易下载核心、基础 Wine runtime 或 idv-login 二进制。共享 runtime 首次使用时从固定原始上游地址下载并逐项校验。
- 高密度性能采集、输入延迟和设备实验已从普通 UI 移除。游戏会话默认仅每 10 秒记录一次最小运行状态；诊断包在本地脱敏后只由用户主动发送。

性能提示：

- 游戏设置里的卡顿检测有时会建议“降低渲染精度”。在本项目已经捕获的约 45–55 FPS 持续波动中，M1 Pro 的 GPU 没有饱和，瓶颈位于游戏/Wine/DXMT 的 CPU 提交或同步一侧；这类波动降低渲染精度通常不会改善，可以保留原画质。
- 这不是对所有 Mac 的绝对结论。A18 Pro MacBook Neo、首代 M1 等较弱 GPU 机型尚未实测；只有设备自身出现 GPU 长期接近满载，或降低分辨率后帧率确实明显回升时，降低渲染精度才可能有效。

键盘与文件夹提示：

- 游戏在前台且功能键租约成功时，标准 F1–F9 保留游戏功能，`Command+F1` 对应游戏的 `Alt+F1`。标准 F10 静音、F11 降低音量、F12 提高音量；按住 F11/F12 可连续调整，Shift 可细调。Command/Control/Option 组合键仍交给游戏。切出游戏后自动恢复原来的顶排键模式。本机这轮功能键租约后来反复失败，内建键盘也不再达到前述效果；Rainy 75 的 F11 与 Fn+F11 都出现系统音量 HUD，另一把外接键盘 F1–F9 可进游戏，但 F10–F12 单按仍触发系统静音/桌面/音量。尚无已验证的外接配置办法。
- F10–F12 控制当前 macOS 默认输出设备；设备须支持软件音量/静音控制。部分 HDMI/数字输出不支持，不能保证此时可调。此功能不切换游戏正在使用的音频设备，也不包含切歌；本机的 Fn 标志不能可靠区分直接按键与 Fn 组合，因此不能承诺 Fn+F10–F12 恢复游戏键位。
- Caps Lock 可能同时触发 macOS 的中英文输入源切换；系统没有可靠的按 App 暂停接口，当前建议在游戏内改绑需要频繁使用的动作。
- Windows 的桌面、文档、下载、图片、音乐和视频目录使用 prefix 内的私有目录；启动器不会要求读取用户真实的 macOS 标准文件夹。

当前状态：默认麦克风 rebinder 已实机验证，不再默认唤醒 iPhone 连续互通麦克风；本机开盖时游戏语音可录入，合盖时内建麦克风不可用，须改用外接输入。修改系统默认输入后需要重启游戏才能可靠生效。国服完整直下、暂停恢复、双阶段更新和新目录启动已通过。国际服 444 个文件、17,602,266,736 字节的完整直下与整树 MD5+xxh64 复验已通过；独立 prefix 不经过官方国际服启动器即可直接运行，约 2.36 GB 首启热更新完成后再次启动也已进入 `release_oversea` 的登录/大厅资源阶段。idv-login 启动状态只有在受管进程树、本地 443 监听和三条 Hosts 同时吻合时才显示就绪。Developer ID 安装态和开盖语音已在本机实测；Rainy 75 外接键盘顶排尚待定向验收，切窗破音本轮未复现。公开发布前仍须核对本 App 与最终源码、许可材料、签名公证和干净安装态，macOS 15 与国际服登录持久化仍分别需要真实设备和实际用户回归。
