# 第五人格启动器 · IdentityV Launcher

第五人格启动器是让 Apple Silicon Mac 运行《第五人格》PC 互通版的非官方项目。此项目无需安装 Crossover、不需要网易发烧游戏平台。你甚至可以用触控板玩。

## 功能介绍

支持国服和国际服的下载、校验、启动、修复和卸载。

支持基于 IDV Login 的账号登录管理。

支持游戏内键盘映射。游戏内 Command 映射为 Windows 的 Alt，MacBook 键盘的 F1-F9 与 Windows 的对应键位效果一致，保留了 F10-F12 的音量控制功能。不影响游戏外的键盘功能。

检测到可能的卡死时提供弹窗一键重启，也可以直接切换到启动器窗口一键重启。

## 使用方法

下载 release 中的「IdentityV-Launcher-1.0.0-rc.1.dmg」

1. 打开 IdentityV-Launcher-1.0.0-rc.1.dmg，将“第五人格启动器.app”拖入“应用程序”。
2. 打开启动器，选择国服或国际服，点击下载游戏，启动器会自动完成下载和安装。
3. 点击启动游戏。

## 注意事项

首次安装和启动会申请一些权限，需要输入密码，第五人格启动器不会收集和上传你的密码。

IDV Login 是非必需的可选登录组件，可以改善账号管理和登录体验，你不安装也能玩。

游戏内的复制粘贴是 Control+C 和 Control+V，而不是 Command+C 和 Command+V。

麦克风输入和音频输出会绑定游戏启动时的设备，中途切换系统的音频设备并不会在游戏内生效，需要重启游戏。

超过 1Khz 回报率的鼠标可能造成异常卡顿。

外接键盘的 F 区映射可能异常。

首次 idv-login 可能启动失败，再试一次就行。

理论上兼容 macOS 15 及以上的 macOS 版本，只在 macOS 27 上进行过实机验证，具体兼容性验证进度同样见变更记录。
