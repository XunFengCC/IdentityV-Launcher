# 第五人格启动器 · IdentityV Launcher

**第五人格启动器**是让 Apple Silicon Mac 运行《第五人格》PC 互通版的非官方项目。玩家可以分别管理国服和国际服的下载、校验、启动、修复和卸载；可选的 IDV Login 组件用于相关登录流程。**第五人格工具箱**是单独构建的维护者 App，用于性能浮窗和按需诊断采集，不是玩家安装启动器的必要条件。

项目仍在开发中，暂未提供公开下载。版本进展与已知问题见[变更记录](CHANGELOG.md)。

适用设备为 Apple Silicon Mac；首版以 macOS 15 为目标，具体兼容性验证进度同样见变更记录。

## 安装与首次使用

取得发行包后：

1. 打开 DMG，将“第五人格启动器.app”拖入“应用程序”。
2. 打开启动器，选择国服或国际服，按界面引导下载并校验游戏。
3. 游戏准备完成后，点击启动；需要修复或卸载时，使用对应游戏的管理入口。

游戏和所需运行组件由启动器按需下载，两服的游戏文件与配置各自独立。IDV Login 是可选登录组件，安装或系统信任步骤可能需要管理员授权；麦克风等权限按实际使用由系统提示。

## 反馈与开发

启动器可在本地生成脱敏诊断包，交给邮件客户端，由你检查后自行发送。
