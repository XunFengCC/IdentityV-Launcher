# 第五人格启动器

`第五人格启动器.app` 是项目唯一对玩家可见的 Apple Silicon 应用。它管理国服与国际服两个独立产品：当前选中的服务器只决定正在查看和操作的面板，不会结束另一服，也不会阻止另一服下载。完整游戏运行器位于 `Contents/Helpers/IdentityVGameRunner.app`，Finder 中不会出现第二个游戏 App。

两服都从各自的网易官方动态 manifest/CDN 直接下载和校验游戏文件，不打开网易发烧平台界面。安装时显示字节进度、速度与 ETA，支持暂停、继续和取消。安装完成后提供启动、结束、重启、修复和卸载游戏。卸载只处理所选服务器已记录且经边界复验的游戏目录、独立 prefix 与安装工作区；另一服、共享 runtime、idv-login 和启动器本身均保留。

idv-login 是可选组件，当前固定上游 6.3.0，二进制不随 App 重分发：玩家同意启用后，启动器才从固定的上游 Release 下载，限制重定向主机并逐项校验大小、SHA-256 和 Mach-O 架构。组件版本或 helper 契约不匹配时显示“更新”；跨版本自动隔离旧热修复，保留账号和证书。启用后，“启动/重启游戏”会先等待 idv-login 本地代理就绪，再由启动器精确启动当前服务器；不让 idv-login 代替启动器选服。

启动器每次打开回到 `720×380` 的紧凑窗口，当次仍可自由缩放。国服/国际服是同一材质分段栏；游戏操作固定在左、安装状态固定在右。IDV Login 运行后提供“重启”“结束运行”和“卸载”三个独立动作，重启会等待旧后台完全结束后再串行拉起。

公开 UI 不再显示高密度监测、输入延迟探针和设备实验。内嵌 runner 在游戏会话期间每 10 秒记录时间、产品、PID、CPU、RSS 与进程状态，不记录输入内容、截图、音频、聊天或网络内容。“问题反馈”会在本地生成包含用户描述和最近低频日志的脱敏 ZIP，再打开写给 `fengyin.apps@icloud.com` 的系统邮件草稿；不会在背景自动上传。用户可检查正文和附件后自行发送，无邮件客户端时界面给出网页邮件补发说明。

## 疑似卡死提醒

启动器默认启用轻量监视器，在“第五人格”菜单中可关闭“疑似卡死时提醒”。关闭启动器窗口后仍继续，明确退出 App 则停止；不依赖工具箱、屏幕录制权限或登录项。每秒核对各服 runner 会话文件及实际 PID 身份，跟随新游戏会话读取游戏自己的新 ANR 标记和 GPU 提交计数。打开时已有的旧 ANR、计数缺失、睡眠间隔和后台停止渲染均不会作为 GPU 卡死信号。

新 ANR 或前台游戏已观察到 GPU 提交推进后约 10 秒不再提交，触发左上区域的小提示，并在 `IdentityVOnMac/Diagnostics/Health` 留最近最多 60 个数值样本。提醒只表示可能无响应，不把静态画面或低 CPU 等同死锁。文案为“游戏可能卡住了”，按钮为“继续等 / 重启游戏”。提示不激活启动器、不取得键盘焦点、不移动指针，也没有键盘快捷确认；点击“继续等”抑制同次停顿重复提示；恢复后新异常可再触发，确认后的五分钟内不打扰。点击“重启游戏”才走已有的产品重启和 IDV Login 准备流程，确认时及实际 dispatch 前均复验同一产品、PID 与进程启动时间。

全屏显示使用随启动器按需启动的 `IdentityVHangPrompt` accessory helper：非激活 NSPanel 内仅有居中短标题和横排系统按钮，无图标，约 262×82。macOS 26 起使用 clear Liquid Glass 及 glass/glassProminent 按钮，旧系统使用 ultraThinMaterial 与 bordered 按钮；文字和按钮保持正常不透明度。当前非 key 面板上的玻璃仍比活跃窗口更灰、更实，尚未达到所期望的通透效果；不以强取焦点换外观。stdin 接收本次提示 ID/短标题，stdout 只返回带同一 ID 的按钮选择，EOF 即退出。NSAlert 的正式模态响应机制无法通过公开 API 同时提供严格不成为 key 的保证，因此没有挪用其内部视图或保留给框架的按钮回调。显示 helper 不含游戏控制、采集或授权能力。`--self-test` 检查协议和非激活面板契约；真实全屏 Space 的视觉结果仍需按最终候选复测。

构建：

```bash
./buildPlayerLauncher.command
```

产物：

```text
./playerLauncherApp/build/第五人格启动器.app
```

构建先刷新内嵌 runner、runtime catalog、音频与输入资源，再嵌入原生下载/管理/诊断 helper。签名从内层代码到外层 App 逐层进行，具体身份由 `signing/lib/signIdentityV.sh` 解析；构建自测使用隔离 HOME，不下载游戏、不启动游戏、不安装 helper，也不请求系统权限。构建候选之后如何运行、更新 `/Applications` 和恢复，见[项目维护入口](../README.md)。
